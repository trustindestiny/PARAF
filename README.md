# PARAF — SAVE MONEY

Paraf kampanyalarını tek ekranda takip etmek için çevrimdışı çalışabilen Progressive Web App (PWA).

## GitHub Pages yayını

1. Repository > **Settings > Pages** bölümünü açın.
2. **Build and deployment > Source** seçeneğini **GitHub Actions** yapın.
3. Actions sekmesinde **Deploy PARAF to GitHub Pages** iş akışının tamamlanmasını bekleyin.
4. Uygulama adresi: https://trustindestiny.github.io/PARAF/

## Telefona yükleme

- iPhone: Safari'de uygulamayı açın > Paylaş > Ana Ekrana Ekle.
- Android: Chrome'da uygulamayı açın > menü > Uygulamayı yükle.

Kampanya verileri, filtreler ve sıralama uygulamanın içinde bulunur. Service worker temel dosyaları önbelleğe alır ve çevrimdışı açılışı destekler.
