# PARAF — SAVE MONEY

Paraf kampanyalarını tek ekranda takip etmek için çevrimdışı çalışabilen Progressive Web App (PWA).

## Kullanım

- Siteyi GitHub Pages üzerinden yayınlayabilirsiniz.
- iPhone: Safari > Paylaş > Ana Ekrana Ekle.
- Android: Tarayıcı menüsü > Uygulamayı yükle.
- Kampanya verileri ve filtreleme uygulamanın içinde yer alır.

Uygulama dosyaları: `index.html`, `manifest.json`, `sw.js`, `icons/`.
